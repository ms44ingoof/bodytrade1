# Body Trade (Fabric 1.20.1)

Мод: алтарь обмена частей тела на ресурсы, последствия, HUD, возврат, шансы.

## Сборка
Автоматически через GitHub Actions: вкладка **Actions** -> последний запуск -> **Artifacts** -> `bodytrade-mod`.
Внутри будет `bodytrade-1.0.0.jar` (и `-sources.jar`, его не нужно). Положите основной jar в `mods` вместе с Fabric API.

## Локально
Java 17 и Gradle 8.7+: `gradle build`, jar появится в `build/libs`.
